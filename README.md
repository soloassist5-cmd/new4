# MinerBot

Клиентский мод для **Minecraft 26.1.2** (Fabric). Бот управляет вашим персонажем как игрок:
ходит, прыгает, целится, ломает и ставит блоки — обычными игровыми действиями, а не телепортом
и не правкой мира напрямую.

Две задачи:

1. **Копка области.** Выделяете параллелепипед, называете блок и инструмент — бот сам доходит
   до каждого такого блока внутри области и выкапывает его.
2. **Дублирование построек.** Выделяете постройку, копируете её, указываете направление и
   количество копий — бот берёт материалы из хотбара и строит.

| Компонент | Версия |
|---|---|
| Minecraft | 26.1.2 |
| Fabric Loader | 0.19.5 или новее |
| Fabric API | 0.155.3+26.1.2 |
| Java | 25 |

## Установка

1. Поставьте Fabric Loader для 26.1.2.
2. Положите в `mods/` файл `minerbot-1.0.0.jar` и [Fabric API](https://modrinth.com/mod/fabric-api).
3. Мод чисто клиентский — на сервере он не нужен.

## Быстрый старт

### Копка

```
/minerbot pos1                       посмотрите на один угол области
/minerbot pos2                       посмотрите на противоположный угол
/minerbot mine iron_ore              копать всю железную руду в области
/minerbot mine iron_ore diamond_pickaxe    тем же, но конкретным инструментом
/minerbot mine all                   копать вообще всё внутри области
/minerbot stop                       остановить
```

Инструмент можно не указывать — бот сам выберет из хотбара самый быстрый, отдавая предпочтение
тому, с которым блок выпадает предметом.

### Дублирование построек

```
/minerbot pos1                       угол исходной постройки
/minerbot pos2                       противоположный угол
/minerbot copy                       снять слепок
/minerbot build south 3              построить 3 копии к югу
/minerbot build facing 1             одну копию в ту сторону, куда вы смотрите
```

Копии ставятся встык: смещение равно размеру выделения вдоль выбранного направления. Для забора
из примера выше это значит, что секции продолжатся ровной линией.

### Клавиши

| Клавиша | Действие |
|---|---|
| `[` | угол 1 (блок под прицелом) |
| `]` | угол 2 |
| `\` | остановить бота |

Клавиши переназначаются в стандартных настройках управления, категория **MinerBot**.

### Остальные команды

```
/minerbot sel            показать текущее выделение
/minerbot sel clear      сбросить выделение
/minerbot status         что сейчас делает бот
/minerbot tunnel on      разрешить прокапываться сквозь блоки вне области
/minerbot tunnel off     (по умолчанию) копать только внутри области
```

## Что бот делает и чего не делает

**Делает:**

- Ходит по-настоящему: A\* по клеткам, куда влезает игрок, с прыжками, спусками и диагоналями.
- Прокапывается сквозь породу, чтобы добраться до руды внутри области — с учётом того, что
  копать твёрдое дорого, поэтому обойти обычно выгоднее.
- Целится в конкретную грань блока и проверяет линию взгляда, поэтому сервер видит те же
  дистанцию и направление, что и клиент.
- Приседает при установке блоков, чтобы не открывать сундуки и не щёлкать рычаги, о которые
  строит.
- Сам выбирает слот хотбара под каждый блок и инструмент.

**Не делает:**

- Не достаёт материалы из основного инвентаря — только из хотбара. Переложить предметы внутри
  инвентаря клиент правдоподобно не может, поэтому бот честно сообщает, чего не хватает, вместо
  того чтобы делать вид, что положил.
- Не плавает. Вода считается непроходимой, маршрут её обходит.
- Не строит леса под висящие в воздухе блоки. Блок без опоры откладывается: обычно опору даёт
  соседний блок, поставленный позже в том же проходе. Если после прохода без единой установки
  что-то осталось — бот останавливается и говорит, сколько блоков поставить не вышло.
- Не работает с сундуками, печами и прочими контейнерами.

**Бот сам отдаёт управление,** если вы нажали клавишу движения, если здоровье упало ниже 4 сердец,
если открыт любой экран или если мир закрылся.

## Как это устроено

| Пакет | Отвечает за |
|---|---|
| `bot` | контроллер задач, желаемый ввод, навигация до цели |
| `path` | A\*, запросы к миру (проходимость, опора, опасность), исполнение маршрута |
| `action` | прицеливание, выбор слота, цикл ломания, установка блоков |
| `task` | сами задачи — копка и стройка |
| `blueprint` | слепок выделенной постройки |
| `selection` | выделение области |
| `render` | подсветка области частицами и строка состояния в HUD |
| `mixin` | подмена ввода и отключение ванильного цикла ломания |

Два места, где мод вмешивается в игру:

- `KeyboardInputMixin` — ванилла каждый тик пересобирает ввод с клавиатуры внутри
  `LocalPlayer#aiStep`, поэтому желания бота дописываются сразу после этого. Вектор движения
  задаётся аналоговым `Vec2`, а не четырьмя «кнопками», так что бот идёт точно в нужную сторону
  независимо от того, куда повёрнута голова.
- `MinecraftMixin` — ванилла в каждый тик без зажатой кнопки атаки сбрасывает прогресс ломания;
  пока бот ломает сам, эта ветка отключается.

## Сборка из исходников

```bash
./gradlew build          # jar в build/libs/
./gradlew runClient      # клиент с модом
```

Нужен JDK 25 — Minecraft 26.1.2 собран под него.

Начиная с 26.1.2 Mojang публикует клиент без обфускации, поэтому слой маппингов (Yarn, Mojmap)
не нужен: мод собирается прямо против настоящих имён из игры.

### Тест

```bash
./gradlew runClientGametest
```

Поднимает настоящий клиент, создаёт мир, командами строит арену и прогоняет бота:
выкапывает патч железной руды 3×3 и копирует забор из трёх секций, после чего проверяет мир.
Исходник — `src/main/java/com/minerbot/gametest/MinerBotGameTest.java`.

## Про сервера

Мод автоматизирует то, что игрок делает руками, и на многих серверах такое запрещено правилами.
Проверьте правила сервера, прежде чем запускать бота не в одиночной игре.
